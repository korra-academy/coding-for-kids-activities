# Coding for Kids — Free Activities & a First Game

Free, screen-light **coding activities for kids aged 5–12**, plus a real browser game written in one HTML file that children can open, read and change. No installs, no accounts, no ads.

Made by [Korra Academy](https://korra.academy/) — the team behind **[Korra.Kids](https://korra.kids/)**, live online coding for children.

## What's inside

1. **12 unplugged coding activities** (below, one added weekly) — teach sequencing, loops, conditionals and debugging away from a screen.
2. **[`first-game.html`](first-game.html)** — a "catch the stars" game in a single file. Download it, double-click it, then open it in any text editor and change the numbers to make the game yours.

## The unplugged coding activities

### 1. Robot parent
Child writes step-by-step instructions ("algorithm") to make you cross the room and pick up a toy. Follow them *literally*. Missing step = bug. Teaches: algorithms, debugging.

### 2. Sandwich program
Write instructions for making a jam sandwich. Execute exactly as written ("put jam on bread" → jar on loaf). Teaches: precision, why computers need exact instructions.

### 3. Loop dance
Invent a 4-move dance. Instead of writing moves 12 times, write "repeat 3 times". Teaches: loops.

### 4. If-then treasure hunt
Cards like "IF the door is open THEN look under the mat ELSE look behind the plant." Teaches: conditionals.

### 5. Human sorting network
Family members each hold a number, sort themselves by comparing pairs only. Teaches: comparisons, algorithms.

### 6. Grid drawing (pixel art)
One person has a picture on squared paper, describes it cell by cell ("row 2: blank, black, black, blank"), the other redraws it. Teaches: how images are data.

### 7. Secret binary messages
A=1, B=2 … or 5-bit binary cards. Write a message, sibling decodes. Teaches: encoding, binary.

### 8. Debug the recipe
Give a recipe/instruction list with 3 deliberate mistakes. Child finds and fixes them. Teaches: debugging mindset.

### 9. Function factory
"Wash-hands" = 6 steps. Once named, you may just say "run wash-hands". Build bigger routines from named ones. Teaches: functions, abstraction.

### 10. Network postman
Write a message, split it into 3 numbered envelopes, deliver them out of order via different rooms; receiver reassembles. Teaches: how the internet sends packets.

### 11. The sock-matching problem
Tip a basket of clean socks on the floor. Round 1: find pairs by grabbing one sock, then hunting through the whole pile for its partner (that's a *linear search* — count how many socks you touch). Round 2: first sort the pile into colour groups, THEN pair within each group. Compare the counts. Teaches: why organising data first makes searching dramatically faster — the idea behind every database index.

### 12. Variable cups
Label three paper cups `score`, `lives` and `level` and put a pile of counters (coins, dried pasta) beside them. Play any simple game — snap, a dice race, skittles with rolled-up socks — but nobody may keep a number in their head. Every change must be said out loud as an instruction and then done to a cup: "set lives to 3", "add 1 to score", "if score is 10 THEN add 1 to level AND set score to 0". If a number isn't in a cup, it doesn't exist — and a cup can only ever hold one value at a time. Teaches: variables — named boxes that store one value — and how a program changes its state one instruction at a time.

## The first game (edit it!)

Open [`first-game.html`](first-game.html) in a browser to play (arrow keys). Then open the same file in Notepad/TextEdit and look for the `SETTINGS` block — every value is safe to change:

- make the stars fall faster
- make your basket huge
- change every colour
- rename the game after yourself

Breaking it is part of the lesson — press Undo and try again.

## FAQ

**What age is this for?**
Activities 1–4 work from age ~5 with help. The HTML game suits ~8+ readers; younger children enjoy changing colours with a parent driving.

**Do we need to install anything?**
No. A browser and any text editor (Notepad is fine).

**What language is the game written in?**
Plain JavaScript inside one HTML file — the same language behind most websites, and a common first text language after Scratch.

**What comes after this?**
Scratch → simple JavaScript projects like this one → guided lessons. If your child wants a live human tutor, that's what we do at [korra.kids](https://korra.kids/).
